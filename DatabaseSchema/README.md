# FMSC DACPAC schema reference

Generated from model.xml only, never exported school rows.

Each XML file holds the complete original DACPAC model element, including nested columns, constraints and relationships. Supported SQL modules also have body-only SQL files. These body files are **not guaranteed executable CREATE statements**; consult the paired XML for signatures. This reference folder is NOT a migration, schema approval, or live database deployment input. Review changes using existing DACPAC controls.
