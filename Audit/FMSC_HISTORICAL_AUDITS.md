## Immutable retrieval and safety

The original files can be viewed or restored without guesswork by opening their links above or selecting the corresponding path from [the Audit folder at `83bb0b6fe272`](https://github.com/farhan2166-creator/FMSC-Database/tree/83bb0b6fe2720bb0ada6da7304dbeac4d4d3de34/Audit). Deleting redundant copies from the current branch will **not** erase the historical commits. The underlying school database, installer scripts, migrations, production code, and test fixtures are not part of this documentation consolidation.

**Policy boundaries preserved:** Never replace existing school MDF/LDF with a DACPAC. For a fresh install, use a verified matched *detached* MDF/LDF pair; validate compatibility and migrations on a disposable clone. Preserve previously accepted roles, admission chronology policy, whole-rupee accounting, transaction recovery and database integrity expectations. Native Windows GUI, physical printing, intended Windows accounts, and production-like data upgrade/rollback require separate release evidence.
