# Student report ready views

Reports → Student Reports → Views offers Parent Contact List, Class Register and Transport Students. Choose a campus/year/class/section first if needed; these choices are retained. Ready views select useful columns, sort by student name and clear other restrictions to start with the existing active-student list. Transport Students selects the visible Uses transport filter. Existing Columns, Print Preview, Export and Save View actions work as before. Custom entries appear as My view: name and remain separately saveable/deletable; built-in views cannot be deleted.

Run `dotnet run --project Tests/StudentReportViewChecks/StudentReportViewChecks.csproj`. Checks cover confirmed versus unknown transport values, unchanged source data, preservation of amounts, ordinary report compatibility and preset columns against the real report catalog.

Windows manual checks: select a class/section and open each ready view; confirm filters and columns, student counts, printed title and export subtitle. Transport must exclude No and unknown records. Change transport after running: printing/export must stay disabled until View Report runs again. Admission Number search must continue to ignore other filters, including transport. Save/reopen a transport view and an older custom view; old views default to All students. Save a custom view with the same name as a built-in view, reopen both, delete only the custom one. Reset Filters must clear transport. Admissions, strength/year comparison and movement reports must remain unchanged. No database migration is required.
