# Class & Section Summary

In Student Reports choose Campus and Academic Year, then Class Summary A4. It reads all classes and sections for that scope, using GetStudentRegister with active enrollment status and the existing ClassOutstandingReportData query. Other Student Report filters, grouping, student search and selected columns do not affect this standalone summary. No additional daily data entry, database writes or migrations.

Each row identifies campus/class/section by IDs, counts active students once per placement, and shows Boys, Girls and Other (including unspecified gender). Balances are positive authoritative charge balances from all eligible charge placements, including former students/placements; they are not restricted to the current active roster. Sections with no debt stay visible, and former placements with debt but no active students stay visible. The final total sums all displayed rows. Unknown gender cannot make the gender totals diverge from active students. No empty/unoccupied placements are invented.

Run `dotnet run --project Tests/ClassSummaryChecks/ClassSummaryChecks.csproj`.
