# Fee reminders

Outstanding & Aging → Fee Reminders loads students with outstanding charges for the campus/year/class/section filters. The existing class outstanding query supplies charge balances; the reminder sums those rows per student, prints the covered scope and does not treat the amount as an unfiltered whole-account balance. It preserves the existing positive-charge and cancelled-charge rules. Nothing is saved or sent to parents automatically.

The selection dialog offers checkboxes, Select All, Clear Selection, an optional Pay by date and an optional message. Balances are refreshed after selection, and students who have paid in the meantime are excluded. The printed date is labelled Requested payment date and does not modify billing due dates. The template uses the existing 2.28-inch receipt paper width and shared content-height measurement, with one student reminder per receipt page. Amounts show two decimal places.

Run `dotnet run --project Tests/FeeReminderChecks/FeeReminderChecks.csproj`.
