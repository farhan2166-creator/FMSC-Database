# Class marks and exam attendance sheets

Open Reports → Class Marks & Attendance Sheets. Choose one campus and academic year, then a class/section or All classes / All sections. Press Load Students to review the roster, uncheck anyone to exclude, then Print Preview. Select All and Clear Selection affect the complete loaded roster. Find Student filters only the displayed list, retaining checked hidden students. Changing campus/year/class/section invalidates the loaded roster; changing sheet type or exam fields retains selections. The roster comes from the existing `GetStudentRegister` procedure with active student/enrollment filters; no balances are requested and no records are saved.

Marks and exam attendance templates use portrait A4 with two identical copies side by side, up to 30 students per data page, alphabetical names and continuous serial numbers across pages. Empty final-page rows stay blank. Rows and header text can grow to retain full names and entered details; unusually long text can require physical continuation pages. Each copy repeats school/campus/year/class/section, exam/subject/date, teacher name/signature and page information. Optional details can be entered before preview or left blank for handwriting. Marks use Written, Oral and Total; exam attendance uses student Signature only.

Marks sheets add the father’s name in parentheses only when selected students share a name; matching ignores case and surrounding spaces. Students sort by name, then father name for ties. Attendance sheets retain plain names.

Run `dotnet run --project Tests/ClassSheetChecks/ClassSheetChecks.csproj`. The checks cover empty rosters, page boundaries, continuation numbering, excluded former/unenrolled students, blank slots, exclusions and compact numbering, checked hidden rows, an empty selection, optional details, A4/page-break definitions and real RDLC HTML processing of both copies for a 61-student class.

HTML rendering was visually reviewed in the cloud. PDF/image rendering and physical A4 pagination depend on Windows graphics and remain manual checks: preview/print 1, 30, 31 and 61 students; confirm no extra blank pages, identical copies, legible long names and teacher fields on every page. Check increased display scaling, scoped selectors and a class with no active students. Uncheck a student and immediately click Print Preview without changing focus; the exclusion must apply to both copies. Search must retain hidden selections. Change class/year during loading: the old query must not populate the new scope. Switching sheet type and editing exam fields must retain student selections; neither operation writes to the database. The shared viewer supplies zoom, pan, page selection and printing. No migration is required.

Select Monthly Attendance Register on the same form for a single full-width landscape A4 copy, with up to 30 students per page and continuous numbering. Month replaces Exam; Subject/Paper and Date are hidden, while Teacher and student choices remain available. The calendar uses the chosen month’s actual length and weekday headings. Nonexistent dates are shaded; weekends remain available and no school holidays or attendance rules are inferred. Cells are blank for marking by hand; no attendance records are saved.
