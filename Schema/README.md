# FMSC database SQL definitions

These SQL scripts are generated by Microsoft DacFx from a **data-free, temporary** DACPAC model.
Table scripts include columns and inline constraints; supported other objects have CREATE scripts.
When DacFx cannot produce a standalone CREATE script, module body-only references are labeled clearly.
Not every model element has a standalone SQL statement: see SchemaManifest.json for coverage.
The authoritative schema remains FMSC.dacpac. Never deploy scripts from this reference folder or treat schema generation as review/approval of a DACPAC change.
